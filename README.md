# Madrasatul Madina Idarah

মাদরাসাতুল মদীনার মাদরাসা, বিভাগ ও খেদমতে খালক পরিচালনার অ্যাপ। Vanilla HTML/CSS/JS দিয়ে বানানো PWA, backend Supabase।

## দ্রুত শুরু

```bash
npm install
cp .env.example .env   # SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY বসান
npm start              # http://localhost:5502
```

বিস্তারিত: [docs/dev/local-setup.md](docs/dev/local-setup.md)
